# E5-S3: Port-out request service with 7-day cooling period

**Epic:** E5 — Suspend/Resume & Port-Out Lifecycle
**Layer:** Service
**Group:** E
**Depends on:** E2-S3, E5-S1

## Description

Service handling port-out request, cancel-within-window (returns to ACTIVE), and finalize/cancel-after-window behavior per AC-07.

## Acceptance Criteria

1. Requesting port-out on an ACTIVE subscription transitions it to PORT_OUT_REQUESTED, creates a PortOutEvent, and appends a StateTransition record.
2. Cancelling a port-out request within the 7-day window returns the subscription to ACTIVE and closes the PortOutEvent with status CANCELLED_WITHIN_WINDOW.
3. Finalizing a port-out request after the 7-day window has elapsed transitions the subscription to PORTED_OUT and closes the PortOutEvent with status FINALIZED.
4. Attempting to finalize a port-out request before the 7-day window has elapsed is rejected with a specific reason code.
5. Requesting port-out on a subscription that is not ACTIVE raises InvalidSubscriberStateException.
