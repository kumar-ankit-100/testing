# E7-S3: Admin reporting API endpoints

**Epic:** E7 — Admin Reporting
**Layer:** API
**Group:** G
**Depends on:** E7-S2

## Description

Admin-only REST endpoints exposing the four report types.

## Acceptance Criteria

1. GET /api/admin/reports/activation-funnel (admin role) returns HTTP 200 with per-stage counts.
2. GET /api/admin/reports/churn returns HTTP 200 with monthly churn values.
3. GET /api/admin/reports/plan-mix returns HTTP 200 with per-plan percentage distribution.
4. GET /api/admin/reports/arpu returns HTTP 200 with a stubbed ARPU trend series.
5. A non-admin principal calling any of the four endpoints receives HTTP 403.
