# E1-S5: Health check endpoint

**Epic:** E1 — Platform Foundations
**Layer:** API
**Group:** B
**Depends on:** E1-S2

## Description

GET /health endpoint that responds with HTTP 200 within 1 second of a successful application startup, satisfying NFR-06.

## Acceptance Criteria

1. GET /health returns HTTP 200 with a JSON body containing a status: 'ok' field.
2. A test measures response latency and asserts it is under 1000ms.
3. /health requires no authentication.
4. A test starts the app and calls /health immediately after startup completes, asserting success without retries beyond the documented backoff policy.
