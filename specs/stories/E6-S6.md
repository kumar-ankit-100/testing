# E6-S6: Subscription termination API endpoint

**Epic:** E6 — CSR Exception Queue & Overrides
**Layer:** API
**Group:** G
**Depends on:** E6-S5

## Description

REST endpoint exposing CSR/admin-only subscription termination (E6-S5), mounted on the existing `lifecycle_router.py` alongside suspend/resume/port-out.

## Acceptance Criteria

1. `POST /api/subscriptions/{subscription_id}/terminate` on an `ACTIVE` or `SUSPENDED` subscription, called by a CSR or admin with a `reason_code`, returns HTTP 200 with `{subscription_id, state: "TERMINATED"}` (AC-02).
2. Calling it on a subscription not in `ACTIVE`/`SUSPENDED` returns HTTP 409 with `reason_code: INVALID_STATE_TRANSITION`.
3. Calling it with a missing/empty `reason_code` returns HTTP 422 with `reason_code: VALIDATION_ERROR`, rejected before any write (AC-09).
4. A subscriber-role principal calling this endpoint receives HTTP 403.
5. Integration tests exercise the full happy path and each error path via the FastAPI `TestClient`.
