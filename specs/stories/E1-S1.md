# E1-S1: Define core domain types and FSM contracts

**Epic:** E1 — Platform Foundations
**Layer:** Types
**Group:** A
**Depends on:** None

## Description

Establish shared domain types (Subscriber, Subscription, PlanVersion, BillingRecord, StateTransition, PortOutEvent, CSROverride, DealerMaster) and the declarative FSM transition table with InvalidSubscriberStateException. These types are the foundation every other layer imports from, per the Types -> Config -> Repository -> Service -> API -> UI architecture.

## Acceptance Criteria

1. SubscriberState enum defines exactly PENDING_KYC, ACTIVE, SUSPENDED, TERMINATED, PORT_OUT_REQUESTED, PORTED_OUT and no other values.
2. A declarative FSM transition table maps each valid (from_state, to_state) pair; calling transition(current_state, target_state) with a pair not in the table raises InvalidSubscriberStateException.
3. Domain types for Subscriber, Subscription, PlanVersion, BillingRecord, StateTransition, PortOutEvent, CSROverride, and DealerMaster are defined with typed fields (no Any), and money fields typed as Decimal.
4. The Types module has zero imports from Config, Repository, Service, API, or UI.
5. Unit tests instantiate each domain type with valid data and assert field types, including that monetary fields reject non-Decimal input.
