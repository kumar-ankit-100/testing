# E6-S1: CSR override repository (append-only, audited)

**Epic:** E6 — CSR Exception Queue & Overrides
**Layer:** Repository
**Group:** B
**Depends on:** E1-S1, E1-S2

## Description

Append-only persistence for CSROverride records capturing actor, timestamp, reason code, and the overridden action.

## Acceptance Criteria

1. Repository exposes create_csr_override and list_csr_overrides_for_subscription; no update/delete function exists.
2. Every CSROverride record stores a non-null actor (CSR user ID), a non-null timestamp, and a non-null reason code.
3. A unit test creates two overrides for the same subscription and asserts both remain retrievable independently.
