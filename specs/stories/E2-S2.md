# E2-S2: Subscriber self-registration service

**Epic:** E2 — Subscriber Registration & Rule-Based Activation
**Layer:** Service
**Group:** C
**Depends on:** E2-S1, E1-S4

## Description

Service that creates a new Subscriber/Subscription in PENDING_KYC state from mobile number, identity-proof reference, and plan type, rejecting duplicate active registrations.

## Acceptance Criteria

1. Registering with a valid mobile number, identity-proof reference, and plan type creates a subscription in PENDING_KYC state.
2. Registering a mobile number that already has an ACTIVE subscription is rejected with a specific error (not a generic 500).
3. Registering with a malformed mobile number (not matching the expected digit pattern) is rejected before any database write.
4. A unit test verifies the identity-proof reference is persisted but is masked when logged.
