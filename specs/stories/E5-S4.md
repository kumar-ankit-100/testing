# E5-S4: Suspend/resume and port-out API endpoints

**Epic:** E5 — Suspend/Resume & Port-Out Lifecycle
**Layer:** API
**Group:** F
**Depends on:** E5-S2, E5-S3

## Description

REST endpoints exposing suspend, resume, port-out request, cancel, and finalize actions.

## Acceptance Criteria

1. POST /api/subscriptions/{id}/suspend on an ACTIVE subscription returns HTTP 200 with state SUSPENDED.
2. POST /api/subscriptions/{id}/resume on a SUSPENDED subscription returns HTTP 200 with state ACTIVE.
3. POST /api/subscriptions/{id}/port-out returns HTTP 200 with state PORT_OUT_REQUESTED and a cooling-period end date in the response body.
4. POST /api/subscriptions/{id}/port-out/cancel within the window returns HTTP 200 with state ACTIVE.
5. POST /api/subscriptions/{id}/port-out/finalize before the window elapses returns HTTP 422 with a specific reason code.
