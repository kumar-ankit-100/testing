# E1-S3: Structured JSON logging with PII masking

**Epic:** E1 — Platform Foundations
**Layer:** Service
**Group:** B
**Depends on:** E1-S2

## Description

Shared logging utility producing structured JSON log lines and masking PII (mobile number, Aadhaar reference, PAN reference) before any log line is emitted, satisfying NFR-03/NFR-05.

## Acceptance Criteria

1. Logger emits each log entry as a single JSON object with at minimum timestamp, level, message keys.
2. A logged mobile number is masked to show only the last 4 digits (e.g., ******7890); the full unmasked number never appears in the emitted JSON.
3. A logged Aadhaar reference and PAN reference are masked using the same partial-reveal rule and never appear unmasked in output.
4. A unit test captures log output for a payload containing all three PII fields and asserts none of the raw values are present as substrings of the emitted JSON.
5. Logger module imports only from Types and Config.
