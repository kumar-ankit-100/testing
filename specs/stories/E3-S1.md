# E3-S1: Plan catalog repository with version history

**Epic:** E3 — Plan Catalog (Versioned, Immutable)
**Layer:** Repository
**Group:** B
**Depends on:** E1-S1, E1-S2

## Description

Persistence for prepaid/postpaid PlanVersion records, append-only across versions, with a lookup for the currently published version per plan.

## Acceptance Criteria

1. Repository exposes create_plan_version, publish_plan_version, get_published_version, and list_versions functions.
2. Calling any update/delete operation against a row already marked published=true raises an error at the repository level (no UPDATE statement executed against published rows).
3. list_versions returns all historical versions for a plan in ascending version-number order, none of them deleted.
4. A unit test attempts to mutate a published plan version's price field directly and asserts it fails.
