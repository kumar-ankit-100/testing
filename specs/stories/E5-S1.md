# E5-S1: State transition and port-out event repositories (append-only)

**Epic:** E5 — Suspend/Resume & Port-Out Lifecycle
**Layer:** Repository
**Group:** B
**Depends on:** E1-S1, E1-S2

## Description

Append-only persistence for StateTransition log entries and PortOutEvent records tracking the 7-day cooling-period window.

## Acceptance Criteria

1. Repository exposes append_state_transition and list_state_transitions_for_subscription; no update/delete function exists for state transitions.
2. Repository exposes create_port_out_event, get_active_port_out_event, and close_port_out_event (closing sets an end status, it does not delete the row).
3. A unit test appends 3 state transitions for one subscription and asserts all 3 remain retrievable in chronological order.
4. create_port_out_event stores the request timestamp and computes/stores the cooling-period end timestamp exactly 7 days later.
