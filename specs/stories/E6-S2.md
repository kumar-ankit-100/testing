# E6-S2: CSR override service — override rejected activation/plan-change

**Epic:** E6 — CSR Exception Queue & Overrides
**Layer:** Service
**Group:** F
**Depends on:** E4-S3

## Description

Service allowing a CSR to override a previously rejected activation or plan-change action, requiring a reason code and recording a full audit entry (AC-09).

## Acceptance Criteria

1. A CSR can override a rejected activation (e.g., DEALER_INVALID) supplying a reason code, resulting in the subscription transitioning to ACTIVE and a CSROverride record being created.
2. A CSR can override a rejected plan-change (e.g., MIN_TENURE_NOT_MET), resulting in the plan change being committed and a CSROverride record being created.
3. Attempting an override without a reason code is rejected before any state change or override record is written.
4. A non-CSR principal (subscriber or dealer-context) attempting an override is rejected.
5. Every override, successful or not, that reaches the persistence step logs a structured entry including the masked actor and reason code.
