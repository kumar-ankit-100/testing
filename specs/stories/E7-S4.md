# E7-S4: Admin reporting dashboard UI

**Epic:** E7 — Admin Reporting
**Layer:** UI
**Group:** H
**Depends on:** E7-S3

## Description

Desktop-first internal dashboard visualizing the four report types for admins.

## Acceptance Criteria

1. Dashboard renders the activation funnel, churn, plan mix, and ARPU trend using data fetched from the four reporting endpoints.
2. Each panel displays a loading state while its endpoint call is in flight and an error state if the call fails.
3. The plan-mix panel labels each segment with its plan name and percentage.
