# E1-S2: Application configuration and stub integration flags

**Epic:** E1 — Platform Foundations
**Layer:** Config
**Group:** A
**Depends on:** None

## Description

Central config module for environment variables, SQLite WAL connection settings, and deterministic stub-integration flags (KYC verified/not-verified, dealer-fail sentinel code, MNP success/fail flag). Config only imports from Types.

## Acceptance Criteria

1. Config module exposes a typed settings object with fields for DB path, KYC stub flag values, dealer-fail code, and MNP stub flag values, loaded from environment variables with documented defaults.
2. SQLite connection is configured with PRAGMA journal_mode=WAL applied at startup.
3. Config module imports only from Types (no Repository/Service/API/UI imports).
4. A unit test asserts that an unset environment variable falls back to its documented default value.
5. A unit test asserts that the dealer-fail trigger code and KYC/MNP stub flags are read as exact string/boolean constants usable by the activation service.
