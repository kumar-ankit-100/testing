# E4-S3: Plan change service — upgrade/downgrade with minimum-tenure rule

**Epic:** E4 — Plan Upgrade/Downgrade with Pro-Rata Billing
**Layer:** Service
**Group:** E
**Depends on:** E2-S3, E3-S2, E4-S2

## Description

Service orchestrating plan-change preview and commit: enforces minimum-tenure rule (AC-04), rejects changes on non-ACTIVE (e.g., SUSPENDED) subscriptions, and persists a BillingRecord on commit.

## Acceptance Criteria

1. A plan-change request on a subscription younger than the configured minimum-tenure period is rejected with reason code MIN_TENURE_NOT_MET and no BillingRecord is created.
2. A plan-change request on a SUSPENDED subscription is rejected with a visible reason code and no BillingRecord is created.
3. A preview call returns the computed pro-rata amount without persisting a BillingRecord or changing the subscription's plan.
4. A commit call on an eligible ACTIVE subscription past minimum tenure updates the subscription's current plan and persists exactly one new BillingRecord matching the previewed amount.
5. Two consecutive commits for the same subscription each produce their own independent BillingRecord (append-only), and the prior record is never modified.
