# E7-S1: Reporting query repository

**Epic:** E7 — Admin Reporting
**Layer:** Repository
**Group:** B
**Depends on:** E1-S1, E1-S2

## Description

Read-only aggregation queries over subscriber, billing, and state-transition data for activation funnel, monthly churn, plan mix, and stubbed ARPU trend (AC-10).

## Acceptance Criteria

1. Repository exposes activation_funnel_counts, monthly_churn_rate, plan_mix_distribution, and arpu_trend query functions.
2. activation_funnel_counts returns counts per funnel stage (registered, KYC-passed, dealer-passed, MNP-passed, activated) that sum consistently (each stage count <= the prior stage count).
3. monthly_churn_rate returns one value per calendar month derived from PORTED_OUT/TERMINATED transitions in that month divided by active base at month start.
4. All returned monetary aggregates (e.g., ARPU) are Decimal, never float.
