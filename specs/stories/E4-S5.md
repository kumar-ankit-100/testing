# E4-S5: Subscriber plan upgrade/downgrade UI

**Epic:** E4 — Plan Upgrade/Downgrade with Pro-Rata Billing
**Layer:** UI
**Group:** G
**Depends on:** E4-S4

## Description

Subscriber-facing screen to preview and confirm a plan change with the pro-rata amount shown before commit.

## Acceptance Criteria

1. Selecting a target plan calls preview and displays the pro-rata amount before any commit action is available.
2. Confirming triggers commit and displays the updated plan and a confirmation of the new billing record.
3. A minimum-tenure or suspended-state rejection displays the exact reason code/message returned by the API.
4. The screen is usable at a 375px mobile viewport without layout breakage, verified by a Playwright test.
