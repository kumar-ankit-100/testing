# E6-S3: CSR exception queue API endpoints

**Epic:** E6 — CSR Exception Queue & Overrides
**Layer:** API
**Group:** G
**Depends on:** E6-S2

## Description

REST endpoints listing pending exceptions and submitting an override with a reason code.

## Acceptance Criteria

1. GET /api/csr/exceptions (CSR role) returns the list of subscriptions with a rejected activation or plan-change awaiting review.
2. POST /api/csr/exceptions/{id}/override with a valid reason code returns HTTP 200 and the resulting subscription/plan state.
3. POST /api/csr/exceptions/{id}/override without a reason code returns HTTP 422.
4. A subscriber-role principal calling either endpoint receives HTTP 403.
