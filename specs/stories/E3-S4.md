# E3-S4: Admin plan catalog management UI

**Epic:** E3 — Plan Catalog (Versioned, Immutable)
**Layer:** UI
**Group:** E
**Depends on:** E3-S3

## Description

Desktop-first internal screen for admins to view plan version history, create a new draft, and publish it.

## Acceptance Criteria

1. UI lists all plan versions for a plan with a visible published/draft badge per version.
2. Admin can submit a form to create a new draft version from the current published version's fields.
3. Attempting to edit a field on a published version in the UI is disabled/blocked, with an inline message directing the admin to create a new version instead.
4. Publishing a draft from the UI updates the visible published badge without a full page reload error.
