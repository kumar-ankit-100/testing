# E4-S4: Plan change API endpoints

**Epic:** E4 — Plan Upgrade/Downgrade with Pro-Rata Billing
**Layer:** API
**Group:** F
**Depends on:** E4-S3

## Description

REST endpoints for previewing and committing a plan upgrade/downgrade.

## Acceptance Criteria

1. POST /api/subscriptions/{id}/plan-change/preview returns HTTP 200 with the computed pro-rata amount and does not mutate state.
2. POST /api/subscriptions/{id}/plan-change/commit on an eligible subscription returns HTTP 200 with the new plan and created billing record ID.
3. Commit on a subscription failing minimum tenure returns HTTP 422 with reason code MIN_TENURE_NOT_MET.
4. Commit on a SUSPENDED subscription returns HTTP 409 with a visible reason code.
5. A subscriber calling these endpoints for a subscription that is not their own receives HTTP 403.
