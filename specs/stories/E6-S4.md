# E6-S4: CSR exception queue desktop UI

**Epic:** E6 — CSR Exception Queue & Overrides
**Layer:** UI
**Group:** H
**Depends on:** E6-S3

## Description

Desktop-first internal screen listing exception-queue items with an override action requiring a reason code, and a visible audit trail per subscription.

## Acceptance Criteria

1. Exception queue list displays each pending item's rejection reason code and subscriber identifier.
2. Submitting an override requires selecting/entering a reason code; the submit action is disabled until one is provided.
3. After a successful override, the item is removed from the pending queue and an audit entry (actor + timestamp + reason) is visible in the subscription's history view.
