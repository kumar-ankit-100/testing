# E3-S2: Plan catalog service — versioning and immutability

**Epic:** E3 — Plan Catalog (Versioned, Immutable)
**Layer:** Service
**Group:** C
**Depends on:** E3-S1, E1-S4

## Description

Service enforcing that published plan versions are immutable; any change requires creating a new version rather than mutating the published one (AC-03).

## Acceptance Criteria

1. Creating a new plan starts an unpublished draft version at version number 1.
2. Publishing a draft version marks it published=true and makes it the active version returned by get_published_version.
3. Attempting to edit a published version's price or terms raises a specific PlanVersionImmutableError rather than succeeding.
4. Requesting a change to a published plan instead creates a new draft version (version number incremented) with the requested fields, leaving the prior published version unchanged and retrievable.
5. Only an admin-role principal can create or publish a plan version; a non-admin attempt is rejected.
