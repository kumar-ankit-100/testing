# E5-S5: Subscriber suspend/resume/port-out UI

**Epic:** E5 — Suspend/Resume & Port-Out Lifecycle
**Layer:** UI
**Group:** G
**Depends on:** E5-S4

## Description

Subscriber screen exposing suspend, resume, and port-out request/cancel actions with the remaining cooling-period countdown shown.

## Acceptance Criteria

1. Suspend and resume buttons are visible only when the corresponding action is valid for the subscription's current state.
2. Requesting port-out displays the 7-day cooling-period end date returned by the API.
3. A 'cancel port-out' action is available and calls the cancel endpoint while within the window.
4. The screen renders correctly at a 375px mobile viewport, verified by a Playwright test.
