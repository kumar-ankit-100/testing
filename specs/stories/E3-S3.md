# E3-S3: Plan catalog admin API endpoints

**Epic:** E3 — Plan Catalog (Versioned, Immutable)
**Layer:** API
**Group:** D
**Depends on:** E3-S2

## Description

Admin-only REST endpoints for creating, publishing, and listing plan versions.

## Acceptance Criteria

1. POST /api/admin/plans (admin role) creates a draft plan version and returns HTTP 201.
2. POST /api/admin/plans/{id}/publish publishes a draft and returns HTTP 200 with published: true.
3. PUT /api/admin/plans/{id} on an already-published version returns HTTP 409 with an immutability error message.
4. GET /api/admin/plans returns the full version history including superseded versions.
5. A non-admin principal calling any of the above endpoints receives HTTP 403.
