# E2-S5: Subscriber self-registration and activation status UI

**Epic:** E2 — Subscriber Registration & Rule-Based Activation
**Layer:** UI
**Group:** F
**Depends on:** E2-S4

## Description

Responsive React screen where a subscriber submits registration details and sees activation status/rejection reason, satisfying the responsive-layout rubric item.

## Acceptance Criteria

1. Registration form collects mobile number, identity-proof reference, and plan type, and submits to the registration endpoint.
2. On activation failure, the UI displays the specific reason code/message returned by the API (e.g., 'KYC not verified').
3. On activation success, the UI displays state ACTIVE.
4. The layout renders correctly (no horizontal overflow, controls usable) at both a 375px mobile viewport and a 1280px desktop viewport, verified by a Playwright test.
