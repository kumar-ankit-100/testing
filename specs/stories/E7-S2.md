# E7-S2: Admin reporting service

**Epic:** E7 — Admin Reporting
**Layer:** Service
**Group:** F
**Depends on:** E2-S3, E4-S3, E5-S2, E5-S3

## Description

Service layer assembling the four report types into presentation-ready structures, restricted to admin role.

## Acceptance Criteria

1. Calling the reporting service for a period with zero activations returns a well-formed empty-but-valid funnel structure (no exception).
2. Plan-mix distribution percentages sum to 100 (within rounding tolerance of 0.1) across all active plans for a given snapshot.
3. ARPU trend values are clearly labeled as stubbed/synthetic in the returned structure's metadata.
4. A non-admin principal invoking the service directly (bypassing the API) still receives an authorization error, not just relying on the API layer.
